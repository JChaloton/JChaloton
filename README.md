**[TSL-ONE: Thai Sign Language Recognition Dataset](https://tsl-one.github.io/)**  
Part of my Master's research, I traveled across 4 regions of Thailand to 9 schools, working with 29 signers to create a comprehensive Thai Sign Language dataset. The dataset contains 4,152 video samples across 184 glosses, freely available for non-commercial research. Advancing accessibility through machine learning and computer vision.
